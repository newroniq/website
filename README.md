# Website

This repo holds the source code of the website. It is a Jekyll site: `index.html`
assembles the page from reusable files in `_includes/`, with styles and behavior
in `assets/css/site.css` and `assets/js/site.js`.

Edit site-wide labels and page copy in `_data/copy.json`. White-paper content is
in `_data/papers.json`; its `content` fields contain HTML so headings, paragraphs,
and lists can be maintained together. Jekyll renders the data into the page when
the site is built.
